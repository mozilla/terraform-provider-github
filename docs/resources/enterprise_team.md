# github_enterprise_team (Resource)

Creates and manages a team at the GitHub Enterprise level. Unlike an organization team, an enterprise team is defined once for the whole enterprise and can then be assigned to organizations within it.

This resource requires a token with enterprise owner permissions, and is only available on GitHub Enterprise Cloud.

~> GitHub derives `slug` from `name`, so renaming a team changes its slug. Reference the team elsewhere through `slug` rather than hardcoding it.

-> Assigning the team to organizations with `github_enterprise_team_organizations` requires `organization_selection_type` to be `selected`.

## Example Usage

```terraform
resource "github_enterprise_team" "platform" {
  enterprise_slug = "my-enterprise"
  name            = "Platform"
  description     = "Engineers who maintain shared platform services."

  # Required before the team can be assigned to organizations with
  # github_enterprise_team_organizations.
  organization_selection_type = "selected"
}

# Membership can instead be synchronised from an identity provider group.
resource "github_enterprise_team" "security" {
  enterprise_slug = "my-enterprise"
  name            = "Security"
  group_id        = "8a7b6c5d-4e3f-2a1b-0c9d-8e7f6a5b4c3d"
}
```

## Schema

### Required

- `enterprise_slug` (String) The slug of the enterprise, as it appears in the enterprise URL.
- `name` (String) The name of the enterprise team.

### Optional

- `description` (String) A description of the enterprise team.
- `group_id` (String) The ID of an identity provider group to synchronise team membership from.
- `organization_selection_type` (String) Which organizations the team is available to: `disabled` for none, `selected` for an explicit list, or `all` for every organization in the enterprise. Must be `selected` to use `github_enterprise_team_organizations`.

### Read-Only

- `id` (String) The ID of this resource.
- `slug` (String) The slug of the enterprise team, derived by GitHub from the team name and prefixed to distinguish it from organization teams.
- `team_id` (Number) The numeric ID of the enterprise team.

## Import

Enterprise teams are imported using the enterprise slug and the numeric team ID, separated by a colon.

In Terraform v1.5.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `id` attribute, for example:

```terraform
import {
  to = github_enterprise_team.platform
  id = "my-enterprise:1234567"
}
```

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
terraform import github_enterprise_team.platform my-enterprise:1234567
```
