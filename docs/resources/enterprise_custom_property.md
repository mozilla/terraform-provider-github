# github_enterprise_custom_property (Resource)

Manages a custom property definition for repositories in a GitHub enterprise.

The definition is available to repositories across the enterprise's organizations. Use [`github_repository_custom_property`](repository_custom_property.md) to set an individual repository's value.

GitHub requires enterprise administrator access to create, update, and delete definitions. GitHub App tokens need the enterprise **Custom properties** permission with write access. See the [GitHub REST API documentation](https://docs.github.com/en/enterprise-cloud@latest/rest/enterprise-admin/custom-properties).

## Example Usage

```terraform
resource "github_enterprise_custom_property" "compliance" {
  enterprise_slug = "example-enterprise"
  property_name   = "compliance"
  value_type      = "multi_select"
  description     = "Compliance frameworks that apply to a repository"

  required       = true
  allowed_values = ["internal", "soc2", "iso27001"]
  default_values = ["internal"]
}
```

## Schema

### Required

- `enterprise_slug` (String) The slug of the enterprise.
- `property_name` (String) The name of the custom property.

### Optional

- `allowed_values` (List of String) The ordered list of allowed values for a `single_select` or `multi_select` property. GitHub allows up to 200 values.
- `default_value` (String) The default value for a scalar property. For `true_false`, use the string `true` or `false`.
- `default_values` (List of String) The default values for a `multi_select` property.
- `description` (String) A short description of the custom property.
- `require_explicit_values` (Boolean) Whether actors must supply an explicit value when setting properties or creating or transferring repositories. Defaults to `false`.
- `required` (Boolean) Whether all repositories in the enterprise are required to have a value for the property. Defaults to `false`.
- `value_type` (String) The type of the custom property. Valid values are `string`, `single_select`, `multi_select`, `true_false`, and `url`. Defaults to `string`.
- `values_editable_by` (String) Who can set property values on repositories. Valid values are `org_actors` and `org_and_repo_actors`. Defaults to `org_actors`.

### Read-Only

- `id` (String) The ID of this resource.
