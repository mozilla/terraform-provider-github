# github_enterprise_cost_center_resources (Resource)

Authoritatively manages the resources assigned to an enterprise cost center. Resources absent from these sets are removed from the cost center; destroying this resource removes all assignments.

This resource is available on GitHub Enterprise Cloud. It requires enterprise billing write permission. The ability to assign particular resource types also depends on the token's role.

~> This resource is authoritative over all four assignment types. Resources assigned outside Terraform are removed on the next apply. Adding a resource that belongs to another cost center reassigns it. Destroying this resource removes all assignments, but keeps the cost center.

~> Use only one `github_enterprise_cost_center_resources` resource per cost center. GitHub does not support duplicate assignments across cost centers.

## Example Usage

```terraform
resource "github_enterprise_cost_center" "engineering" {
  enterprise_slug = "my-enterprise"
  name            = "Engineering"
}

resource "github_enterprise_cost_center_resources" "engineering" {
  enterprise_slug = "my-enterprise"
  cost_center_id  = github_enterprise_cost_center.engineering.cost_center_id

  users            = ["octocat"]
  enterprise_teams = ["ent:platform"]
}
```

## Import

Import assignments using the enterprise slug and cost center ID, separated by a colon.

In Terraform v1.5.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `id` attribute, for example:

```terraform
import {
  to = github_enterprise_cost_center_resources.engineering
  id = "my-enterprise:2eeb8ffe-6903-11ee-8c99-0242ac120002"
}
```
