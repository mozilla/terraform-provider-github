# github_enterprise_role_team (Resource)

Manage an association between an enterprise role and an enterprise team.

This resource requires enterprise administration permissions. The API is only available for GitHub Enterprise accounts and is not available for Copilot Business without GitHub Enterprise.

## Example Usage

```terraform
resource "github_enterprise_team" "security" {
  enterprise_slug = "my-enterprise"
  name            = "Security managers"
}

resource "github_enterprise_role_team" "security" {
  enterprise_slug = github_enterprise_team.security.enterprise_slug
  role_id         = 8030
  team_slug       = github_enterprise_team.security.slug
}
```

### Required

- `enterprise_slug` (String) The slug of the enterprise, as it appears in the enterprise URL.
- `role_id` (Number) The unique identifier of the enterprise role.
- `team_slug` (String) The slug of the enterprise team to assign the role to.

### Read-Only

- `id` (String) The ID of this resource.

## Import

Enterprise role team associations are imported using the enterprise slug, role ID, and enterprise team slug separated by colons. Enterprise team slugs contain an `ent:` prefix, so the identifier normally has four colon-separated segments.

In Terraform v1.5.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `id` attribute, for example:

```terraform
import {
  to = github_enterprise_role_team.security
  id = "my-enterprise:8030:ent:security-managers"
}
```

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
terraform import github_enterprise_role_team.security "my-enterprise:8030:ent:security-managers"
```
