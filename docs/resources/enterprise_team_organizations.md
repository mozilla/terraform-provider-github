# github_enterprise_team_organizations (Resource)

Authoritatively manages the organizations a GitHub enterprise team is assigned to. Any organization the team is assigned to that is not listed here is unassigned. The team's `organization_selection_type` must be `selected`.

This resource requires a token with enterprise owner permissions, and is only available on GitHub Enterprise Cloud.

~> The team's `organization_selection_type` must be `selected`. GitHub rejects assignments for teams set to `disabled` or `all`.

~> This resource is authoritative. Any organization assigned to the team outside Terraform is unassigned on the next apply, and destroying the resource unassigns every organization.

-> `team_slug` forces replacement. Renaming the team changes its slug, which destroys and recreates this resource.

## Example Usage

```terraform
resource "github_enterprise_team" "platform" {
  enterprise_slug             = "my-enterprise"
  name                        = "Platform"
  organization_selection_type = "selected"
}

resource "github_enterprise_team_organizations" "platform" {
  enterprise_slug = "my-enterprise"
  team_slug       = github_enterprise_team.platform.slug

  organization_slugs = ["my-org", "my-other-org"]
}
```

### Required

- `organization_slugs` (Set of String) The slugs of every organization the enterprise team should be assigned to.
- `team_slug` (String) The slug of the enterprise team to assign to organizations.

### Read-Only

- `id` (String) The ID of this resource.

## Import

Enterprise team organization assignments are imported using the enterprise slug and the team slug, separated by a colon. Enterprise team slugs themselves contain a colon, so the identifier below has three parts.

In Terraform v1.5.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `id` attribute, for example:

```terraform
import {
  to = github_enterprise_team_organizations.platform
  id = "my-enterprise:ent:platform"
}
```

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
terraform import github_enterprise_team_organizations.platform my-enterprise:ent:platform
```
