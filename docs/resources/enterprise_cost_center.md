# github_enterprise_cost_center (Resource)

Manages a cost center in a GitHub enterprise. Deleting this resource archives the cost center.

This resource is available on GitHub Enterprise Cloud. It requires enterprise billing write permission. Enterprise owners and billing managers can also manage cost centers.

~> Deleting this resource archives the cost center in GitHub. GitHub's API does not permanently delete it.

~> `ai_credit_pool_enabled` can only be enabled for cost centers containing users or enterprise teams. Manage assignments with `github_enterprise_cost_center_resources`.

## Example Usage

```terraform
resource "github_enterprise_cost_center" "engineering" {
  enterprise_slug        = "my-enterprise"
  name                   = "Engineering"
  ai_credit_pool_enabled = true
}
```

## Schema

### Required

- `enterprise_slug` (String) The slug of the enterprise.
- `name` (String) The name of the cost center, up to 255 characters.

### Optional

- `ai_credit_pool_enabled` (Boolean) Whether the cost center draws from its own capped AI credit pool. GitHub permits this only when its resources are users or enterprise teams.

### Read-Only

- `ai_credit_pool_current_amount` (Number) The current amount of the AI credit pool, when reported by GitHub.
- `ai_credit_pool_target_amount` (Number) The target amount of the AI credit pool, when reported by GitHub.
- `azure_subscription` (String) The Azure subscription associated with the cost center, if any.
- `cost_center_id` (String) The GitHub ID of the cost center.
- `id` (String) The ID of this resource.
- `state` (String) The state of the cost center.

## Import

Import a cost center using the enterprise slug and cost center ID, separated by a colon.

In Terraform v1.5.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `id` attribute, for example:

```terraform
import {
  to = github_enterprise_cost_center.engineering
  id = "my-enterprise:2eeb8ffe-6903-11ee-8c99-0242ac120002"
}
```
