# github_enterprise_team_members (Resource)

Authoritatively manages the members of a GitHub enterprise team. Any member of the team that is not listed here is removed from it. Enterprise teams have no per-member role, so members are given as a plain set of usernames.

This resource requires a token with enterprise owner permissions, and is only available on GitHub Enterprise Cloud.

~> This resource is authoritative. Anyone added to the team outside Terraform is removed on the next apply, and destroying the resource removes every member.

~> Do not use this resource on a team whose `group_id` links it to an identity provider group. GitHub manages membership of those teams, and the two will fight.

-> `team_slug` forces replacement. Renaming the team changes its slug, which destroys and recreates this resource — removing every member and adding them back.

## Example Usage

```terraform
resource "github_enterprise_team" "platform" {
  enterprise_slug = "my-enterprise"
  name            = "Platform"
}

resource "github_enterprise_team_members" "platform" {
  enterprise_slug = "my-enterprise"
  team_slug       = github_enterprise_team.platform.slug

  members = ["alice", "bob", "carol"]
}
```

## Schema

### Required

- `enterprise_slug` (String) The slug of the enterprise, as it appears in the enterprise URL.
- `members` (Set of String) The usernames of every user that should be a member of the team.
- `team_slug` (String) The slug of the enterprise team to manage membership for.

### Read-Only

- `id` (String) The ID of this resource.

## Import

Enterprise team membership is imported using the enterprise slug and the team slug, separated by a colon. Enterprise team slugs themselves contain a colon, so the identifier below has three parts.

In Terraform v1.5.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `id` attribute, for example:

```terraform
import {
  to = github_enterprise_team_members.platform
  id = "my-enterprise:ent:platform"
}
```

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
terraform import github_enterprise_team_members.platform my-enterprise:ent:platform
```
